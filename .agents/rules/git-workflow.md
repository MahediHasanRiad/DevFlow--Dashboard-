# Git & Commit Conventions

## Conventional Commits
Use standard conventional commit prefixes:
- `feat:` A new feature
- `fix:` A bug fix
- `docs:` Documentation-only changes
- `refactor:` Code changes that neither fix a bug nor add a feature
- `test:` Adding or updating tests
- `chore:` Tooling, build system, or dependency updates

## Commit Guidelines
- Write concise, imperative commit messages (e.g., `feat: add user authentication flow`).
- Keep commits atomic and logically separated.
