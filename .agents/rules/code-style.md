# Code Style & Quality Rules

## Naming Conventions
- **Variables & Functions**: `camelCase`
- **Classes, Types & Interfaces**: `PascalCase`
- **Constants & Enums**: `UPPER_SNAKE_CASE`
- **Files & Folders**: `kebab-case` or `snake_case` (consistent per project language)

## Coding Standards
- Prefer explicit types and interfaces over `any`.
- Keep functions small, focused on a single responsibility.
- Use early returns to reduce nesting depth.
- Clean up unused imports, dead code, and temporary console logs before finalizing code.
